# 系统管理员前端

系统管理员复用后端已有的 `super_admin` 角色（旧用户类型 `2`，登录响应中仍称“超级管理员”），不新增角色编码或默认账号。普通用户登录进入 `/user/home`，会议室管理员进入 `/manager`，系统管理员进入 `/system-admin/users`。注册仍只能创建普通用户。

系统管理员与其他两类页面并列，提供用户管理、日志查询两个模块。页面采用现有 Element Plus、浅蓝背景、卡片、侧栏和顶部账号栏；窄屏时导航切换为横向排列。

## 登录和权限

沿用邮箱密码登录以及 `SessionId`。进入系统管理路由时，前端调用新接口 `GET /user/session`，读取后端 Session 中的真实角色；该接口不返回 Session 密钥。缺少 Session 返回登录页；角色不是 `super_admin` 则返回其对应页面并提示权限不足。后端各业务接口继续按实际权限校验，日志服务仍独立验证 Redis Session 和管理角色。前端角色判断不能替代服务端鉴权。

退出调用 `/user/logout` 使服务端 Session 失效，然后清除本地登录状态。

会话校验属于只读请求，单次超时 4 秒，遇到网络错误或 5xx 最多再试一次；401 才清理登录会话并回登录页。403 或暂时不可用会停止本次跳转并提示原因，登录页保留“重试进入”按钮，无需重复提交密码登录。登录成功提示放在跳转完成后显示。HTTP 拦截器仅在 401 对应的 Session 与浏览器当前 Session 相同时清理状态，避免旧请求的迟到响应覆盖新登录。

## 用户管理

- 列表、关键词/角色筛选、分页、新增、编辑、删除确认。
- 字段包括用户名、姓名、邮箱、手机号、角色、状态；编辑时密码留空不修改原密码。
- 接口沿用 `/api/user/all`、`/api/user/add`、`/api/user/update/{id}`、`/api/user/{id}`。
- 服务端校验必填字段、邮箱、密码长度、角色编码及账号状态；返回展示数据前解密邮箱，移除密码哈希与邮箱哈希。
- 历史邮箱解密失败时，仅该行返回 `email=null` 和 `emailUnavailable=true`，界面标注“历史邮箱无法解密”，不让单条异常阻断整个列表。该过程不修改数据库原密文；编辑邮箱留空会省略该字段，保留旧值，只有显式输入正确邮箱后才重新加密保存。
- 当前列表沿用既有接口最多 1000 条的限制，在已加载结果内筛选和分页；若实际用户规模超过此范围，需要扩展服务端分页。
- 当前对接会议室业务已有的用户管理接口，数据归属会议室兼容用户库；没有对独立 `user-service` 的导入库实施双写或数据同步。若后续全面切换用户数据源，应统一替换这些接口与登录数据源。

## 日志查询

使用 `POST /api/v1/logs/query`，由网关转发日志服务。必须启动网关、日志服务、Redis 和 ClickHouse，且 ClickHouse 中存在 `meetingroom_logs.access_events`。日志查询依赖已采集数据，不生成模拟记录。

支持时间范围、服务名、trace ID、用户、设备、命令、HTTP 状态筛选，服务端分页和全部字段详情。时间范围最多 31 天；前端转换为 UTC ISO 时间发送，展示时转换为浏览器本地时间。503 等异常显示明确错误提示。

## 验证

- `npm run build`：前端生产构建。
- 当前机器 Node 24 偶发原生进程退出；已用 `npm exec --yes --package=node@22 -- node node_modules/vite/bin/vite.js build` 验证构建通过，仍有原有大包体积提示。
- `mvn -pl backend -Dtest=SystemAdminUserTest test`：匿名/普通用户拒绝、输入校验、用户列表脱敏、编辑空密码保留。
- 浏览器模拟接口回归：`node frontend/tests/system-admin-smoke.mjs <playwright/index.mjs绝对路径>`。先运行前端 preview 于 `127.0.0.1:5175`；脚本覆盖登录分流、路由鉴权、用户增改删、日志查询/详情、503。模拟接口回归不替代真实数据库与 ClickHouse 联调。
- 登录恢复回归：前端 dev 运行在 `127.0.0.1:5173` 时，运行 `node frontend/tests/login-recovery.mjs <playwright/index.mjs绝对路径>`，覆盖首次 503、持续 503 后手动重试、真实 401 和首次校验超时。

后端修改包含新的 Session 身份查询接口，测试新页面前需重新编译并重启会议室后端。不会自动创建系统管理员账号，使用已有 `super_admin` 账号登录。
